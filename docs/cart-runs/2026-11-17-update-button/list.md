  Spec ref: brief > Done when, Inferred
  What to build:
  **(a) Knowing.** One small service in `src/ROROROblox.App/Updates/` that holds "is an update waiting, and of which kind": none, a Store update waiting, or a direct-download update staged (with its version). It raises a change event and never throws.
  - *Store installs* (`IDistributionMode.IsPackaged`): ask `Windows.Services.Store.StoreContext.GetDefault().GetAppAndOptionalStorePackageUpdatesAsync()`; one or more results means an update is waiting. Put the WinRT call behind a one-method interface so tests never touch it, and write the real implementation so that every failure (no Store identity on a sideloaded package, no network, the Store service off, a COM error) is caught, logged once at Debug, and reads as "none".   - *Direct-download installs*: `UpdateChecker` already finds, downloads and stages an update with `WaitExitThenApplyUpdates(..., silent: true, restart: false)`. When it has staged one, it tells the service the version. Do not change what it downloads or when it applies.
  - *Dev builds* (neither): nothing is ever waiting.
  **(b) Showing.** A button in the main window's header button group (`MainWindow.xaml`, the group that holds Games, Settings and the Tools drop-down, around line 1650), at the left end before Games, visible only while an update is waiting. It needs an accessible name (`AccessibleNamingFenceTests`' unnamed ceiling is asserted as equality) and a tooltip that says what the click does. Check compact mode: if the header group is hidden there, say where the button should go in compact mode or that it is not shown, and why.
  - Store: label "Update available"; the tooltip says it opens RoRoRo in the Microsoft Store. The click opens `ms-windows-store://pdp/?productid=9NMJCS390KWB` through the existing `IShellOpener`. The product id is already in the keystone; put it in one named constant.
  - Direct-download: label "Quit to update"; the tooltip says the new version is downloaded and installs when RoRoRo closes. The click takes the same quit path the tray's Quit takes. It does not restart the app.
  - Wording is sentence case, second person where a person is addressed, no exclamation marks, no "new and improved". Name the version in the direct-download tooltip if it is known.
  **(c) Strings.** English in `Strings.resx` by hand; the same keys in `docs/store/translations/ui-<culture>.json` for de, es, fr, pl, pt-BR and ru, matching each catalog's existing terms for "update", "quit" and "Microsoft Store" (search each catalog first); then `python scripts/gen-culture-resx.py <culture>` for each.
