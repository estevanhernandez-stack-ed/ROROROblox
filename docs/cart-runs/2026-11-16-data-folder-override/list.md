  Spec ref: brief > Done when, Inferred (dev build, absolute path)
  What to build: The helper gains a one-time configuration call that sets an override folder. A pure function decides eligibility from three inputs (is the process packaged, is there an `Update.exe` one level above the app folder, the value of `RORORO_DATA_DIR`) and returns either the folder to use or the reason it is not used: unset, not a dev build, or not an absolute path. `Program.Main` calls it straight after `VelopackApp.Build().SetArgs(args).Run()` and before `Localization.UiCulture.ApplyFromSettings()`, because that line already reads `settings.json`.
