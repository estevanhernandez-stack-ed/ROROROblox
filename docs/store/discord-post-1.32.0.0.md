# Clan Discord post — v1.32.0.0

> Post when the Store listing actually shows 1.32, not when certification clears — same rule as
> every post since 1.21. Setup.exe users get it within a day of the GitHub release regardless, so
> if the release is published first this post can go out on that and say so. **Certification
> passing is not Published.** If this goes out before the listing flips, the Store line is wrong.
>
> **It opens on the problem everyone in here has had:** leaving alts running overnight and finding
> some of them kicked in the morning, windows still open, looking fine from across the room. That's
> the whole reason for the feature, and nobody needs to be named for it.
>
> **The verification-page line is in the post on purpose.** People in here know that page. "RoRoRo
> never touches it" heads off the question "does it solve captchas now?" before anyone asks it in
> the channel, where the answer would travel further than the post.
>
> **Join via friend gets a heads-up for anyone who already ticked it.** Until now only Squad Launch
> used it; now the Launch button does too. Someone who ticked it and forgot will meet a new question
> the first time their main isn't in a game, so the post tells them the one-click way out.
>
> **What is deliberately NOT in here:** the plugin reason code, the Launch multiple main-only wait,
> the private-link rule, the known issues (the release notes carry them), and Ur Task 0.9.1 (the
> catalog has served it since 2026-09-29, before this release existed).

---

```
**RoRoRo v1.32 is out** 🎉

Store: it'll arrive on its own, or open the Store app and hit "Get updates."
Setup.exe folks: it updates itself as usual.

**Alts that get kicked come back on their own.**
You know the one: leave alts running overnight, wake up, and a couple
are sitting on the Disconnected screen, window still open, looking fine
from across the room.

Right-click an account and turn on **Rejoin if it drops out**. If that
account's Roblox window is open but it's been out of the game for 3
minutes, RoRoRo closes it and joins it again: back into the same
server, or through your main if it's a Join via friend account.
• Covers idle kicks, failed joins, and the "Verifying you're not a bot"
  page. RoRoRo never touches that page. It closes the window and joins
  again.
• At most 3 rejoins an hour per account. After that it turns itself off
  for that account and pings you, so it can't loop all night.
• Your own Stop always wins. Not offered for your main.

**Join via friend works everywhere now.**
If an account has Join via friend ticked, every launch follows your main,
not only Squad Launch. If your main isn't in a game, RoRoRo asks instead
of joining directly.
Ticked it on an account that doesn't need it anymore? Hit "It's fixed,
join directly" once and it's sorted.

Nothing else moved. Accounts, themes, plugins, alerts, history and
settings all carry over.
```
