# Clan Discord post — v1.27.0.0

> Post when the Store listing actually shows 1.27, not when certification clears — same rule as
> every post since 1.21. Setup.exe users get it within a day of the GitHub release regardless.
>
> **Short on purpose.** There is exactly one piece of news in this release and it explains itself
> in three lines. Padding it with the other work would bury it.
>
> **The lead is "you don't have to do anything."** For most of this clan the honest answer is that
> nothing changes — they're on English and the app was already in English. Saying so early is
> what keeps the post from reading like it's asking for something. The people this matters to
> will know within one sentence.
>
> **The path is stated exactly: Settings → Appearance → Language.** Language is a heading inside
> the Appearance panel, not a top-level item. The in-app notice said "Settings › Language" when it
> first shipped and was wrong; it's fixed, and this post is not going to repeat the mistake.
>
> **"Tell me if something reads wrong" is a real offer, not politeness.** A bad string is a
> one-line edit to the catalog and a re-run of the pipeline. Worth inviting, because a native
> speaker in this Discord will catch things no review pass did.
>
> **What is deliberately NOT in here:** the resource architecture, the string counts, the phases,
> the fence tests, anything about how it was built. Also no "1,017 keys" brag — a number nobody
> can feel. The build story covers all of that for people who want it.
>
> **If 1.24/1.25/1.26 never got posted,** this still works standing alone: it names no prior
> version and assumes nothing about what someone last read. Combined notes are the other option
> and would be a different, longer post.

```
**RoRoRo v1.27 is out** 🎉

Store: it'll arrive on its own, or open the Store app and hit "Get updates."
Setup.exe folks: it updates itself as usual.

**RoRoRo speaks your language now**

The whole app — every menu, button, tooltip and window, and the messages it
writes while you're using it — is translated into French, German, Russian,
Portuguese (Brazil), Polish and Spanish.

You don't have to do anything. It follows whatever language Windows is set
to. If that's English, nothing changes for you.

Want a different one? Settings → Appearance → Language. It switches while
you're looking at it — no restart. The list only offers languages that are
fully translated, so you'll never land on a half-English screen.

If something reads wrong in your language, tell me. That's a quick fix and
you'll catch things I can't.

Setup.exe: https://github.com/estevanhernandez-stack-ed/ROROROblox/releases/latest
```
