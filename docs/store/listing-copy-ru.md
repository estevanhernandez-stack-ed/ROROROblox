## Long description

```
Мульти-лаунчер для Windows.

RoRoRo — это лаунчер для Windows, который запускает несколько клиентов Roblox на одном ПК одновременно, каждый под отдельным сохранённым аккаунтом, принадлежащим вам. Добавьте аккаунты один раз через собственную страницу входа Roblox, а дальше запускайте любой из них одним кликом — в игру по умолчанию, на сохранённый приватный сервер или по любой вставленной ссылке на игру.

Что вы получаете:
• Мульти-инстанс в один клик. RoRoRo удерживает мьютекс-одиночку Roblox, поэтому дополнительные клиенты открываются, а не выводят на передний план первый.
• Шифрованное хранилище аккаунтов (DPAPI). Сохранённые cookie шифруются через Windows Data Protection API с привязкой к вашей учётной записи Windows — скопированный на другой ПК файл хранилища не расшифруется. Перенос аккаунтов между своими ПК — только через осознанный экспорт, защищённый парольной фразой.
• Живой статус каждого аккаунта. Видно, какой аккаунт в какой игре, кто простаивает и как долго; лимит FPS задаётся на каждый аккаунт и держится.
• Squad Launch + Friend Follow. Отправьте все выбранные аккаунты на один приватный сервер, зайдите за другом на его сервер или соберите свои аккаунты на одном публичном.
• Контроль памяти + Recycle. RoRoRo изучает, сколько оперативной памяти клиент Roblox реально стоит на вашей машине, и предупреждает до того, как она закончится. Один клик закрывает тяжёлый клиент и возвращает его на тот же сервер.
• Одно окно инструментов. Игры, настройки, история, диагностика, плагины, «Известные проблемы Roblox» и «О программе» — страницы одного окна рядом с аккаунтами, с горячими клавишами повсюду — F1 показывает список.
• Темы. Четыре встроенные, включая одну, где смысл никогда не передаётся одним цветом, плюс конструктор собственных тем из десяти цветов с обменом файлами.
• Оповещения по желанию — на рабочий стол, в Discord или на телефон. Направьте каждое оповещение в любое сочетание: уведомления на рабочем столе, созданный вами вебхук Discord или телефон через Pushover либо ntfy. Вылеты аккаунтов, предупреждения о памяти, завершения Recycle и сигнал «всё в порядке» каждые два часа. Свежая установка не делает ни одного вызова оповещений — ничего не отправляется, пока вы сами всё не настроите.
• Значок в системном трее меняет цвет по состоянию — статус мульти-инстанса виден с одного взгляда; двойной клик запускает основной аккаунт.
• Система плагинов. Необязательные плагины работают отдельными процессами и не имеют разрешений, пока вы не выдадите их каждому по имени.
• Автообновление через Velopack. Удалённая конфигурация отслеживает актуальную версию Roblox и имя мьютекса, чтобы переименование на стороне Roblox не выбивало вас надолго.
• Доступность, проверенная измерением. Каждый элемент управления сообщает своё имя вспомогательным технологиям, а контраст проверяется по отрисованным пикселям в каждой теме.
• Говорит на вашем языке. Всё приложение — каждое меню, настройка, подсказка и окно, а также сообщения, которые RoRoRo пишет во время работы, — переведено на французский, немецкий, русский, португальский (Бразилия), польский и испанский, в соответствии с языком Windows или вашим выбором в настройках. Переключение происходит мгновенно, а список предлагает только полностью переведённые языки, поэтому вы никогда не попадёте на наполовину английский экран.

Приватность и безопасность:
RoRoRo никогда не видит ваш пароль Roblox. Вход происходит целиком на собственной странице Roblox, встроенной во фрейм Microsoft Edge WebView2 — тот же HTML, то же HTTPS-соединение, что и в браузере. RoRoRo забирает только сессионный cookie, который Roblox ставит после входа, и шифрует его перед записью на диск. Никакой телеметрии. Никакой аналитики. Машину не покидает ничего о вас, кроме обращений к Roblox при запуске — тех же, что делает Roblox.com из браузера, — и, только если вы сами это настроили, оповещений на ваш вебхук Discord или выбранный push-сервис (Pushover или ntfy). RoRoRo также скачивает собственные подписанные файлы из своих релизов на GitHub — обновления, настройки совместимости с Roblox и список известных проблем Roblox — и ничего о вас для этого не отправляет.

Важно: товарные знаки и аффилиация.
«Roblox» и логотип Roblox — товарные знаки Roblox Corporation. RoRoRo — независимый сторонний инструмент, не связанный с Roblox Corporation, не одобренный и не спонсируемый ею. Товарный знак используется исключительно для описания совместимости с платформой Roblox. RoRoRo запускает официальный клиент Roblox без изменений — без инъекций, без хуков, без вмешательства в процесс Roblox; перед запуском он лишь удерживает именованный мьютекс Windows, чтобы последующие экземпляры клиента видели проверку синглтона уже занятой.

Продукт 626 Labs.
```
