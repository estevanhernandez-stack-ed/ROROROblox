# Clan Discord post — v1.36.0.0

> Post when the Store listing actually shows 1.36, not when certification clears, same rule as every
> post since 1.21. Setup.exe users get it within a day of the GitHub release regardless.
>
> **It opens on what they'll see the second the update lands:** the numbers under every account. That
> is the change nobody can miss, so it leads; the Library follows because "where did Games go?" is the
> first question this channel would ask.
>
> **The quit line is in here,** short. A Store update that lands while RoRoRo runs can fail to install,
> and this channel runs RoRoRo all day.
>
> **One known issue is in here:** the health badges haven't been seen on a real account. This channel
> has the expired and flagged accounts that would show them, so asking for a screenshot is the fastest
> way to see one.
>
> **Deliberately NOT in here:** the idle-time and tray-process fixes (real, but nothing for a player to
> do), Diagnostics' install channel, the translations and the fences.
>
> **The trailer link:** only if the YouTube upload is live by the time this posts. The hub page already
> carries it.

---

```
**RoRoRo v1.36 is out** 📊

Store: quit RoRoRo first (right-click the tray icon, Quit), then let the
Store update it. Setup.exe folks: it updates itself as usual.

**Every account shows its numbers now.** Robux, Plus, friends online and
when it last played sit right under each account, plus a note you can
write yourself ("clan bank", "farm alt", whatever helps). Streamer mode
hides the numbers.

**Open any account.** Click the little triangle before its name and its
recent games, favourites and private servers drop down. One click plays
any of them as that account.

**Badges tell you what's wrong.** Session expired, Needs verification,
Limited by Roblox. Click the badge and it starts the fix. If one of your
accounts shows one, post a screenshot here: we haven't seen these on a
real account yet.

**Games is now the Library.** Everything you've played, favourited or
saved, as tiles or a list. Search it, filter it, paste any game or
private server link, and use Play as to pick who plays.

Nothing else moved. Your accounts, themes, plugins and history carry over.
```
