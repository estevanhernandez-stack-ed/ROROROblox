# What's new in this version — v1.37.0.0

> Paste the matching fenced block into Partner Center → your app → **Store listings** → *What's new
> in this version*: the English block for the en listing, and each translated block for its own
> language listing. (Since v1.28 the rows go in through the listing console instead; the blocks are the
> same either way.)
>
> **Written for someone on the v1.36 Store install.** Single-version delta, and a small one: four
> changes, all found in the 2026-11-10 evidence sweep (`docs/cycles/2026-11-10-growth-and-quality/board.md`).
> The launch dead end leads because it is the one a new Store user is most likely to hit.
>
> **The rating ask is disclosed here on purpose.** It is the first time the app asks its user for
> anything, and saying so in the update note is cheaper than someone wondering where it came from.
>
> **Left out on purpose:** how the missing handler is detected, the Windows dialog's wording, the test
> fences, the README and the analytics script. Nothing about plugin contracts.
>
> **The two closing paragraphs are v1.36's, unchanged, in every language.** They passed the listing
> verifier then; only the headline and the four bullets are new text.
>
> Register follows each existing sheet: **vous** in French, **вы** in Russian, **du** in German,
> informal elsewhere. Product nouns stay English: RoRoRo, Roblox, Microsoft Store, FPS.
>
> Sources: `docs/cycles/2026-11-10-growth-and-quality/board.md`, `docs/decisions.md` (four entries
> dated 2026-11-10).

## English

```
v1.37.0.0

Fewer dead ends on the way in

• If this PC has no Roblox that RoRoRo can start, RoRoRo now
  says so and shows you the download, instead of a Windows
  message. This happens when Roblox came from the Microsoft
  Store: get it from roblox.com, and both can stay installed.
• Adding an account you already saved no longer makes a second
  copy. RoRoRo refreshes its sign-in and tells you to add a
  different Roblox account to run two at once.
• New FPS caps: 75, 100 and 180, for monitors that run at those
  rates.
• After a few good days, RoRoRo may ask once for a rating on the
  Microsoft Store. Either answer ends it for good.

Quit RoRoRo before updating from the Store: right-click the tray
icon and choose Quit.

Nothing else moved. Accounts, themes, plugins, history and every
other setting carry over untouched.
```
