# Clan Discord post — v1.31.0.0

> Post when the Store listing actually shows 1.31, not when certification clears — same rule as
> every post since 1.21. Setup.exe users get it within a day of the GitHub release regardless, so
> if the release is published first this post can go out on that and say so. **Certification
> passing is not Published** (1.30: `Certification` → `Release` while the listing still served
> 1.29). If this goes out before the listing flips, the Store line is wrong.
>
> **This one is written for the two people it is about, without naming them.** Twice a clan member
> said "I think RoRoRo has a problem" and it was Roblox. The post says that was a fair guess and
> thanks them for raising it, because raising it is exactly what built both answers. Naming them
> would turn a thank-you into a callout in front of the clan.
>
> **The notice gets a warning of its own.** Everyone who updates sees one notice about the freezing
> window, because that entry is marked serious and has no Roblox version bound. Unannounced, a new
> banner the day after an update reads as the update breaking something. So the post says it is
> coming and what to do with it.
>
> **The freeze fix is in the post, not just a pointer to it.** The clan member who hit it is in this
> channel; "cap that account at 60" is the thing they can act on today, and "Windows key, then
> Escape" gets a frozen window moving again. Both are the entry's own words.
>
> **What is deliberately NOT in here:** signatures, the four-hour timer, the 256 KB cap, the cache,
> the CI work, the #213 translation-pipeline backfill (nobody saw a difference), and Ur Score 0.6.2
> (the catalog has served it since 2026-09-23, before this release existed).

```
**RoRoRo v1.31 is out** 🎉

Store: it'll arrive on its own, or open the Store app and hit "Get updates."
Setup.exe folks: it updates itself as usual.

**Is it RoRoRo or is it Roblox? Now RoRoRo tells you.**
Twice now someone in here has said "I think RoRoRo has a problem" and it
turned out to be Roblox. Totally fair guess — RoRoRo is the thing you
opened — and thank you for saying something, because both times that's
what got it fixed. The first one is how the memory watchdog and Recycle
happened.

So there's a new page: **Tools → Known Roblox issues** (or Ctrl+7 in the
tools window). Each Roblox problem we know about, what to do, and a
button straight to the RoRoRo feature that helps. The list updates on
its own, no new version needed.

**You'll see one notice after you update. That's this, not a new bug.**
It's about the Roblox window that freezes when you drag or resize it.
Hit "See known issues" to read it, or close it and it stays closed.

If that freeze has been getting you:
• Press the Windows key, then Escape — the window moves again.
• Set that account's frame-rate cap to 60. That stops it for most people.

Also on the list: Roblox eating more memory the longer it runs (about
300 MB an hour per client, even idle). Keep the memory watchdog on and
use Recycle — it puts the account right back in the same server.

Seen a Roblox problem that should be on the list? Tell us here.

Nothing else moved. Accounts, themes, plugins, alerts, history and
settings all carry over.
```
