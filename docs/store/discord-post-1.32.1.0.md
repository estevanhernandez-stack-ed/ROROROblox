# Clan Discord post — v1.32.1.0

> Post when the Store listing actually shows 1.32.1, not when certification clears — same rule as
> every post since 1.21. Setup.exe users get it within a day of the GitHub release regardless, so if
> the release is published first this post can go out on that and say so. **Certification passing is
> not Published.** If this goes out before the listing flips, the Store line is wrong.
>
> **It opens by telling people it wasn't them.** Anyone who unticked memory watching and kept
> getting warnings has been quietly wondering whether they misread the switch. The post says the
> switch was the problem, in the first line, because that is the only part of this release anyone
> felt.
>
> **No mechanism.** "Read once at startup" is a sentence for the release notes. In here it is "it
> only took hold the next time you opened RoRoRo", which is the same fact in the words someone would
> use to describe what they saw.
>
> **Short on purpose.** One fix. A post padded out to look like a feature release teaches the channel
> to skim the next one.
>
> **What is deliberately NOT in here:** the known issues (the release notes carry them, including the
> balloon that ignores your destination ticks — that one is being fixed in the next release and
> announcing a bug we have already scoped reads as a warning rather than news), the Ur Score 0.7.0
> catalog entry (it has been served since the night 0.7.0 shipped, before this release existed), and
> the screen-reader toggle fix, which belongs to the people it affects rather than to a clan channel.

```
**RoRoRo v1.32.1 is out** 🧠

Store: it'll arrive on its own, or open the Store app and hit "Get updates."
Setup.exe folks: it updates itself as usual.

**Turning memory watching off now actually turns it off.**

If you ever unticked "Watch memory while accounts are running" and kept
getting memory warnings anyway — that was a real bug, and it wasn't you
misreading the switch. Unticking it saved your choice but only took hold
the next time you opened RoRoRo, so the warnings kept coming in the
session you were sitting in.

Now it stops the moment you untick it, and starts again the moment you
tick it back. No restart either way.

The three numbers under it are live too — how much RAM to keep free, when
to warn about one account, and how far ahead to warn. Change one and the
very next check uses it.

Nothing else moved. Accounts, themes, plugins, alerts and history all
carry over untouched.

Download: https://github.com/estevanhernandez-stack-ed/ROROROblox/releases/latest
```
