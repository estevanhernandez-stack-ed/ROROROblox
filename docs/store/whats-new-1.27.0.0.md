# What's new in this version — v1.27.0.0

> Paste the matching fenced block into Partner Center → your app → **Store listings** → *What's new
> in this version* — the English block for the en listing, and each translated block for its own
> language listing. All seven live in this file rather than seven side files, because the workflow
> is paste-per-listing and one file is what you actually work from.
>
> **Written for someone on the v1.25 Store install.** The Store never received v1.26 — it was held
> back for being only half localized — so this audience has never seen *any* of the localization.
> The headline is therefore the whole thing ("RoRoRo speaks your language"), not v1.27's
> completion of it. The one mechanism worth teaching is that the picker only lists
> fully-translated languages, and that switching is now immediate.
>
> Path wording: the nav item is **Appearance** (the Language section lives inside it), so every
> block names Appearance in that language's own UI word — matching the in-app notice.

---

## English

```
v1.27.0.0

RoRoRo speaks your language
• The whole app — menus, settings, every window, and the
  messages RoRoRo writes as you use it — is translated into
  French, German, Russian, Portuguese (Brazil), Polish, and
  Spanish. If Windows is set to one of those, RoRoRo picks it
  up on its own.

Switch any time, instantly
• Settings > Appearance lists only the languages RoRoRo is
  fully translated into, so you never land on a half-translated
  screen. Pick one and the app changes over immediately — no
  restart.

Still English at heart
• English stays the default, and product names — Squad Launch,
  Recycle, RoRoRo itself — read the same in every language.
  Nothing about your accounts, themes, or settings changes.
```

## What is deliberately not in this copy

- **That v1.26 existed.** The Store audience is on v1.25 and never received v1.26; narrating "we
  finished what we started" would reference a version they never had. The GitHub release notes,
  written for the direct-download users who *do* have v1.26, tell that story instead.
- **How many strings.** "1,017 strings" is an engineering number. "The whole app" is what a
  customer feels.
- **The verification pipeline.** How the translations were checked is not a customer concern.
